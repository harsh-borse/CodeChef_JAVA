## Problem

### MCQ - 22

What will be the output of this code, if the user enters a = 5 and b = 9?

```
import java.util.*;
class Codechef {
    public static void main(String[] args) {
        Scanner read = new Scanner(System.in);
        int a = read.nextInt();
        int b = read.nextInt();
        System.out.println(a + "" + b + "" + (a + b)); // "" is empty string and not single space
    }
}

```
